## Portfolio - 5 Production Projects

### 01 - FieldMitra Voice Ops™
Problem: Officer has no time to type, needs trust score in 10 seconds.
Solution: Voice + 1-click score. Stack: Python, Streamlit.
Impact: Officer can check 50 customers in 1 hour.

### 02 - Recovery Tracker API™
Problem: Pending list in Excel, no one knows who to visit first.
Solution: FastAPI with /pending sorted by risk. Stack: Python, FastAPI, SQLite.
Impact: High-risk customers first, recovery improves.

### 03 - Ops Copilot™
Problem: Officer asks manager same questions daily.
Solution: AI copilot answers from real field data. Stack: Python, Gemini API.
Impact: Manager time saved, officer gets instant answer.

### 04 - Field Ops SQL Analytics™
Problem: Manager does not know which village is risky.
Solution: SQL village-wise analytics. Stack: SQL, Python.
Impact: Village risk visible in 1 report.

### 05 - Deploy Ops Docker™
Problem: App works on my laptop, not on manager laptop.
Solution: Docker pack, run anywhere. Stack: Docker, Python.
Impact: Deploy in 2 minutes anywhere.
